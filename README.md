<br/>

An intelligent study assistant that ingests user notes, builds a semantic knowledge base via RAG, and generates contextual quizzes, summaries, and concept maps. Designed to reduce passive re-reading and replace it with active, AI-mediated recall.

| Attribute | Detail |
|-----------|--------|
| **Stack** | React, Node.js, Express, PostgreSQL, OpenAI API, LangChain, Vector DB |
| **Scale** | Multi-user, session-persistent knowledge graphs |
| **Performance** | Sub-second semantic retrieval via vector similarity search |
| **Security** | JWT-authenticated sessions, scoped vector namespaces |
| **Impact** | Flagship RAG/LLM project; core resume centrepiece |
| **Repository** | [github.com/CyborgX-hash](https://github.com/CyborgX-hash) |

The architecture separates ingestion (chunking + embedding), retrieval (cosine similarity ranking), and generation (LLM synthesis with context injection) into distinct, independently scalable services — a pattern that mirrors production RAG deployments at scale.

</details>

<details>
<summary><strong>Queue Cure '26 — Real-Time Clinic Queue Management System</strong></summary>

<br/>

A live clinic queue orchestration platform built during a hackathon sprint. Patients join virtual queues via QR or web, receive real-time position updates via WebSocket, and clinic staff manage flow through a live dashboard — eliminating physical waiting.

| Attribute | Detail |
|-----------|--------|
| **Stack** | Node.js, Socket.IO, Supabase, React, Vite |
| **Scale** | Multi-clinic, concurrent patient sessions via WebSocket channels |
| **Performance** | Real-time position broadcasting with <100ms event latency |
| **Security** | Supabase row-level security, clerk-authenticated staff views |
| **Impact** | Hackathon submission; demonstrable civic-tech impact |
| **Repository** | [github.com/CyborgX-hash](https://github.com/CyborgX-hash) |

The system architecture leverages Supabase's Postgres real-time subscriptions alongside Socket.IO for hybrid push delivery — ensuring state consistency across browser sessions without client polling.

</details>

<details>
<summary><strong>Satellite AI — Generative Cloud Removal for LISS-IV Imagery</strong></summary>

<br/>

A deep learning pipeline that removes cloud occlusion from LISS-IV satellite imagery using generative models. Explored diffusion models, conditional GANs, and SAR data fusion (Sentinel-1/Sentinel-2) to reconstruct occluded surface features.

| Attribute | Detail |
|-----------|--------|
| **Stack** | Python, PyTorch, FastAPI, React + Vite, Sentinel Hub API |
| **Scale** | Tile-based processing for multi-resolution satellite imagery |
| **Performance** | GPU-accelerated inference on M2 Pro; batch tile generation |
| **Security** | API-gated inference endpoints via FastAPI middleware |
| **Impact** | Satellite AI Hackathon (June 2026); applied research showcase |
| **Repository** | [github.com/CyborgX-hash](https://github.com/CyborgX-hash) |

Framed as an applied research project bridging geospatial data engineering and generative deep learning, with production API delivery via FastAPI and a React-based visualisation frontend for inspecting before/after imagery outputs.

</details>
